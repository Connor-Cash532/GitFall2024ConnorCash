git log gives the commit history of the repository. Each commit shown in git log has an id, author, date, and commit message. git status shows the differences in files between the last commit and the local repository. The output shows the files in the staging area, the untracked files, and the modified files not in the staging area.
git shortlog groups the commits in the repository with each author. It gives a simplified output compared to git log where it gives an author and under the author is their commits with the commit message.
To see commits that included Main.java as part of the committed files you would use the command git log -- Main.java
To see differences in commits that included Main.java you use the command git log --summary -p -- Main.java
To see git commits with a certain word in the commit message you use the grep flag with log, so the command would be git log --grep="account" --oneline.
To see git commits from a certain author you use the author flag, so to see the commits made by me I would use the command git log --author="Connor Cash"
